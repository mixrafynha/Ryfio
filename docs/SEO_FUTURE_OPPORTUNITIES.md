# SEO Future Opportunities

These recommendations are intentionally not implemented because they require visible-content or business-policy decisions:

- Add more specific, user-approved visible product/category copy where current text is generic.
- Add verified brand/product identifiers to product data if the business has them.
- Add approved shipping and returns information to support Merchant Center offers.
- Consider genuine localized pages and hreflang only when translated routes and localized fulfillment actually exist.
- Improve internal-link coverage only through an approved navigation/content change.
- Consider performance work on server timing, bundle size, third-party requests, and image delivery only after browser measurement proves it preserves the current experience.

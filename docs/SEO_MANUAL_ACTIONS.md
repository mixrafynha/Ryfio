# SEO Manual Actions

After deployment:

1. In Google Search Console, verify the canonical `https://www.ryfio.com` property.
2. Submit `https://www.ryfio.com/sitemap.xml`.
3. Inspect the homepage, catalog, each custom-product page, blog index, and every active product URL.
4. Request indexing only for important public URLs that are not discovered naturally.
5. Review Pages/Indexing reports for redirects, duplicate canonical, crawled-not-indexed, and blocked-by-robots findings.
6. Run Rich Results Test on representative product pages and resolve only data-backed validation errors.
7. In Merchant Center, configure shipping, returns, tax, countries, and product data source only after the readiness requirements are confirmed.
8. Monitor Search Console impressions, clicks, CTR, average position, product rich-result enhancements, and excluded-page reasons weekly after launch.

Do not remove existing verification files or tokens. Do not add analytics IDs or tracking scripts without authorization.
